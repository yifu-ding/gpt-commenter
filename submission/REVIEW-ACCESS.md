# Reviewer setup

MarkAtlas has no publisher login or paid subscription. Never package credentials.
The submitting organization must have local-MCP submission access. Reviewers need
a supported Apple Silicon Mac, a compatible desktop host, and a locally executing
thread. Install the exact desktop ZIP and copy review-fixtures to a scratch folder.

The required cases avoid background AI explanation requests, so they do not need
the publisher's Codex CLI account. For optional CLI explanation coverage, use the
reviewer's own authorized sign-in or host sampling. Never share the publisher's
tokens or production account. Any required reviewer credentials belong only in
the portal's secure fields.

Before claiming readiness, verify installation and all review cases in the host;
the packaging smoke check alone does not prove desktop UI, screenshot handoff,
or account-dependent explanation behavior.
