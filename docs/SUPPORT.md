# MarkAtlas support

MarkAtlas is developed by Zihao Jing. Report bugs and request help through
[GitHub Issues](https://github.com/zihao-jing/gpt-commenter/issues).

Include your macOS version, processor type, MarkAtlas version, desktop host,
steps to reproduce, and any error message. Use a small example file that you
have permission to share. Do not post credentials, private documents, or other
people's personal information in public issues. There is no guaranteed response
time or paid support service.

The desktop package targets Apple Silicon Macs. PDF review requires the PDF
utilities described in the release's README. Explanations require host sampling
or a signed-in Codex CLI; LaTeX compilation uses your own toolchain. A source
ZIP requires installation of development dependencies and a build; a desktop
ZIP does not require npm. Follow the host's supported plugin installation flow.

For deletion of local plugin data, see the [privacy notice](PRIVACY.md).
