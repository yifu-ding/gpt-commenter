# Local Obsidian appearance

These are exact local copies of the active Blue Topaz theme and notation-purple snippet from the user's vault. The original attribution/license comments are retained in the CSS. This is a personal local build; review upstream licensing before redistributing it.

`node build-theme.mjs` scopes theme rules to Markdown previews and bundles KaTeX fonts. Obsidian configuration and source CSS are not modified. Obsidian app chrome and community plugins are not included.
